# Image generation V1 archive

This directory is a source archive of the local/PC image-generation feature as
it existed immediately before the chat-focused rebuild. Files keep their
original relative paths. Nothing under `archive/image-generation-v1` is part of
the Android source set or active application build.

The archive contains the image API client, models and file service, generation
and settings screens, plus snapshots of every shared integration file and its
compatibility test.

## Deliberately retained in the active app

The active app still contains the generic `Attachment` model and the image
attachment viewer. This lets old conversations display, enlarge and save images
that were generated by earlier versions. Generation metadata remains readable,
and deletion is restricted to files inside the app-owned `generated_images`
directory.

Existing image-generation Preferences are no longer read or written, but an app
update does not clear their old keys. Existing generated files remain under the
private `files/generated_images/` directory. Do not delete that directory as
part of feature removal. A normal chat archive records local paths rather than
embedding image binaries, so it is not a cross-device image backup.

## Restoration notes

Restore the archived service and screens deliberately, then reconnect them to
the current navigation/ViewModel/settings APIs. Do not replace the retained
attachment compatibility code with the old snapshots without reviewing newer
chat changes first.
