# 3.0.17 — 手表连接与待同步内容恢复

## 修正

- 手表首页直接提供“立即同步”“断开”“重新配对”，断开后有“连接原手机”，不再藏在感知菜单中。
- 修复配对死循环：手机生成新码后旧凭据失效，但手表旧版又因待同步内容拒绝配对。同一手机、同一会话、同一人设重新认证时保留队列和消息编号，自动补传。
- 显示真实待同步消息、事件、状态及回复任务数量；可查看消息并选择补传或重新配对。
- 切换其他手机/会话/人设需确认。旧内容留在应用私有数据库备份，不会误发给新会话。“旧会话”可以查看，并提示通过重新配对原会话恢复。
- 切换时暂停感知与同步；SQLite 事务保护原记录，失败不清空。新凭据先以暂停状态保存，防止中途中断后混发旧数据。备份不含令牌、配对码或 API Key。
- 暂停后重新连接不会偷偷重新开启身体感知；需要时在“感知与连接”中开启。

## 验证范围

真实 SQLite 数据队列保留、隔离、恢复、回滚测试和手表页面按钮测试。手机聊天、模型、TTS 与主动联系业务未改动。实际手机蓝牙重配对仍需两端设备确认，不以模拟测试冒充实机链路成功。
