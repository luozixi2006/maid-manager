# 3.0.7 界面与陪伴

本轮只整理界面呈现和陪伴外观控制，不修改模型请求、聊天历史、文件工具、TTS、记忆或事件判定。

## 统一界面

- `AppPrimitives` 统一无描边输入框、分组容器、分组标题、折叠帮助和开关。
- 聊天页移除单独占一行的后台任务入口，改到顶部任务按钮；顶栏、聊天区和输入区保持同色。
- 服务、搜索、人设、记忆、数据、外观、更新等页面使用一致的中性色、留白和分组。模型选择取消描边。
- 任务、陪伴、自动提醒各有独立页签。任务默认摘要，展开查看操作；帮助折叠，关键数据使用同意与操作确认仍保留。自动规则在点“添加”后显示创建表单。

## 陪伴头像与关闭

设置 → 任务与陪伴 → 陪伴 → 更换头像。调用系统照片选择器，复用已有有界照片导入：纠正方向、缩放、重新编码并去除 EXIF。图片复制到私有存储；照片选择权限失效后仍可显示。头像配置独立于人设和历史任务，切换任务不覆盖自定义头像；“还原”回到跟随头像。

“显示悬浮头像”开关关闭会停止服务并移除悬浮窗，不取消任务。悬浮面板右上角 `−` 收起、`×` 关闭；通知栏保留关闭。服务销毁后拒绝再次渲染，避免待结束的聊天回调把已关闭窗口重新挂回去；不设置后台自启动。

“主动展开提醒”关闭后，头像保持收起，系统通知和任务继续工作。它不等于取消任务或关闭事件规则，说明在“关闭与隐私说明”内可查看。

收起态仅头像和状态点；展开态为内容高度自适应、最大半屏滚动内容的轻量面板。使用原生自绘圆角、头像、文本按钮，无默认灰色系统按钮和硬编码黑字。主题跟随应用设置和系统深浅变化。

## 验证

`UiVisualTest` 用 Robolectric 原生图形与 Compose 绘制真实页面，生成设置、任务、陪伴、服务编辑的截图；`CompanionUiTest` 覆盖独立头像配置和面板收起/关闭按钮回调，并生成原生陪伴组件浅深色截图。输出位于 `app/build/reports/ui/`，不是 AI 效果图。

截图测试是 Android 渲染环境下的布局检查，不代表真实手机上完成了相册选择、跨 App 拖动、输入法和厂商悬浮权限验证。实机应补测：换头像 → 关闭 → 重启头像仍保留；任务更新不覆盖头像；快速聊天中关闭不重新出现；深浅切换可读。
