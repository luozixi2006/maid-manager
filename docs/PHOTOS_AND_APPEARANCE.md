# 照片与个人化（3.0.3）

## 发送照片

聊天输入框左侧「+」可打开照片图库或系统相机。一次最多 4 张，可预览并移除；支持只发照片，也支持图文一起发送。
照片经手机本地解码、方向修正和等比压缩后存入应用私有目录，重新编码时去除 EXIF 元数据。长边最多 1600 像素，单张最多 2 MB。
随后通过当前兼容服务的 `/chat/completions` 发送 `text` 与 `image_url` 内容数组，图片为 JPEG Base64。
文字消息保持原有格式；旧照片会随原消息参与后续多轮对话。图片本身不进入错误日志。

需要模型支持图片输入。请在设置中的官方模型目录确认视觉能力，纯文本模型无法因安装新版而获得看图能力。
官方兼容格式参考：https://docs.siliconflow.cn/docs/userguide/capabilities/vision 。

本地照片与头像不会因为普通覆盖更新而删除。当前 JSON 聊天导出保留图片路径，不内嵌照片文件；不能把 JSON 导出当成跨设备照片备份。

## 名字与头像

- 人设备注：在人设列表说明这个人设的用途。
- 对话名字：可选；设置后聊天、提示词中的名字和主动通知使用此值。
- 留空：自动使用人设备注，旧版人设无需迁移操作。
- 头像：从图库选择或拍照；保存在手机本地，可移除。

点击聊天顶部头像或名字即可进入当前人设编辑。修改备注不会覆盖已设置的对话名字。

## 外观

主题根部使用 Surface 同时提供背景和前景色，避免深色模式继承默认黑色文字。
输入、Markdown、设置导航统一使用主题语义色，默认明暗配色的正文对比度回归测试要求至少 4.5:1。
设置采用分组列表，页面切换使用短淡入淡出，并保留切换设置时的聊天草稿。

设计参考：https://developer.apple.com/design/human-interface-guidelines/dark-mode 。
