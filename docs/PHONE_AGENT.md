# 通用手机任务 · 3.0.6

在现有“交给我做”入口输入目标。采用观察 → 工具 → 真实结果 → 下一轮规划，而不是一次生成固定 PDF 清单。新任务 engineVersion=2；旧任务字段保持兼容，仍由原执行器恢复。当前服务必须提供可用的 OpenAI Compatible 文本接口；没有绑定某个模型品牌，模型须能按 JSON 描述工具。

## 实际工具

共 24 个工具（包括询问与完成）：

- 文件：list_files、read_file、mkdir、copy、move、rename、write_text、trash、restore。
- 原生系统：list_apps、open_app、open_url、share_file、calendar_event。
- 信息：web_search、read_notifications。
- 可选页面操作：read_screen、tap、type_text、scroll、back、home。
- 控制：ask、finish。

文件范围由用户选择共享存储中的 Download、Documents、DCIM 等现有目录及子目录。模型不能扩大根目录、访问应用私有数据或 Android 特殊目录。任意普通文件可复制/移动/改名；只读取 20MB 内文本或 PDF 前 10 页，每次最多 12000 字符，无 OCR。列表每页 100 项，支持分页和名称筛选。文本另存新文件，不覆盖；同名增加序号。不能批量永久删除、执行代码或安装软件。

trash 将单个文件移至授权目录的 `.maid-recovery/`，恢复 ID 与原路径记录在步骤结果，后续 restore 使用真实 ID；没有永久删除工具。复制/写入在 `.maid-staging/` 创建唯一临时文件、完成校验后移动至目标。进程强杀可能留下未完成暂存文件，不把它当成功，不自动清理未知文件。

## 授权与隐私

系统权限逐项独立，由用户开启；未授权时保存当前步骤并暂停。页内确认按工具和范围记录，目录、应用变化不复用批准。恢复已有任务时可显式更新应用授权名单，撤销全局名单立即生效。

读取指定目录的必要文字会发送给创建任务时选定的模型服务；创建前必须同意。页面和通知正文另行逐次确认。通知只读取选定应用当前通知，过滤常见验证码通知及数字串；不保证自动识别一切敏感信息，敏感应用不要加入名单。系统应用列表也会用于任务规划。所有任务/观察/执行记录保存在本机 SQLite，不上传到独立后端。

移动、建目录、改名、复制、新文本、打开应用、滚动/返回可选择范围内自动批准。页面读取/点击/输入、通知正文、恢复区移除/恢复、分享、日程、网页打开每次确认。模型传入的批准、已完成和执行凭据全部丢弃。

无障碍必须用户主动开启并选择允许的应用。只读取当前前台应用的可见节点；不在服务回调里持续收集页面。锁屏、密码字段、系统设置/权限/安装器禁止操作。点击/输入/滚动必须带最近真实观察的快照和节点 ID，页面变化拒绝执行；一次页面操作后必须重新读取。确认界面展示目标控件说明。没有坐标盲点、截图、OCR 或手势注入工具，WebView/游戏等不暴露节点的页面可能无法操作。

打开应用和网页、分享文件、添加日程通过系统 Intent：任务暂停并提供“打开系统操作”，由前台发起。分享选收件人及日程最终保存交给用户。用户回答标为用户确认，不伪装成程序验证。界面发送等不确定效果中断后要求核对，不盲目重放。

## 恢复与运行

每个文件变更先持久保存精确目标和 SHA-256，再执行。完成后/写记录前被杀可核对结果。源文件改变或目标冲突停在原步，不覆盖、不猜测。其他有副作用操作中断必须人工检查后再规划。

最多 80 轮后暂停确认费用与范围；连续三次异常暂停，错误中心记录安全错误类型。用户暂停/取消只停止后续，不撤回已经完成的动作。WorkManager + 前台通知调度；Android 强行停止/厂商限制不能绕过，重新打开可恢复，不能保证无限后台存活。

悬浮头像、快速聊天和事件触发沿用现有实现。触发规则仍是先建议后执行，默认关闭；文件触发目前仅监测下载范围 PDF。时间/应用/Wi-Fi 等是尽力检测，不是实时监听保证。普通主动提醒不会自动扫描文件。

## 验证

自动测试包含：真实本机 HTTP 假模型两轮规划 → Android 工具结果回传 → 完成；SQLite 关闭重开恢复；权限缺失保持步骤；不确定原生操作不重放；旧确认令牌无效；文件复制/移动/文本/可恢复移除与恢复；模型伪造凭据、路径越界和旧页面快照拒绝。HTTP 假模型用于确定性执行器测试，不代表线上模型效果。

本轮开发电脑没有连接 Android 设备。尚未实机验证：厂商后台存活、跨 App 无障碍、悬浮窗/输入法、系统分享及日程保存。先在副本目录与非敏感应用测试，核对批准 → 执行 → 中途结束进程 → 恢复。不要据 APK 构建成功认定可以无人监管操作任何应用。

## 维护边界

`tasks/agent/AgentPolicy.kt` 集中注册工具和批准规则；`AgentEngine` 负责迭代与检查点；`AgentFiles` 管理受限文件；`NativePhoneTools` 使用原生 API；`PhoneAccessibility` 是最后一层可选适配。共享聊天、TTS、记忆实现不为此重构。
