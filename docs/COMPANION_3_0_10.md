# 3.0.10 工作区与页面陪伴

## 本轮修复

- 区分“系统未授权无障碍”和“已授权但服务暂未连接”。重新连接后恢复等待权限的任务，保留执行游标；不会每项任务都跳回系统授权。
- 工作区以目标、当前进度、用户决策为中心。已执行步骤默认折叠，原始输出仍可查看；示例只填入草稿，不执行。
- 用户明确确认后，可记住新工作的常规操作批准设置。仅在已经选定的应用/目录内生效。文件内容访问仍单独确认；删除、付款、发送、发布及不明按钮不自动批准。关闭开关撤销默认，新旧任务设置互不暗中扩大。
- 文字感知可以选择随下次悬浮陪伴恢复，默认不记住；系统无障碍授权不会由应用自行打开。关闭页面感知会撤销记忆选项。

## 真正的画面陪伴

打开悬浮头像后，在悬浮聊天中点“共享画面给她看”，或在屏幕陪伴设置中点“共享画面”。首次说明截图将发送给当前人设模型，再进入 Android 系统选区授权。Android 14+ 建议只分享一个应用；旧系统可能只提供整个屏幕。

需要能接收图片的模型（与普通聊天照片使用同一 `image_url` 请求格式）；纯文字模型不能凭此获得视觉能力。服务器拒绝图片时明确报错，不伪装看见页面。共享不录制视频、不保存截图，只在点击“看看当前页面”或人设主动问候检查时，截取单张最长边 1280 像素的 JPEG，内存发送。自己的悬浮聊天会短暂隐藏，避免把悬浮窗当成正在看的内容。

通知、悬浮窗、设置均可停止共享。关闭悬浮窗也停止共享。停止后旧结果不再发布。系统停止共享、锁屏或进程死亡不能复用旧授权；新的共享会话必须重新确认，不能承诺永久无授权运行。旋转/选区变化复用同一虚拟显示并更换输出 Surface，不二次使用授权 Token。

画面共享的选区由系统管理，不采用文字感知的应用白名单。若选择全屏，用户必须留意切换应用后的内容；不能保证截图中的所有敏感文字都自动识别。系统安全画面不能绕过。截图只是上下文，不是模型操作权限，也不能把页面中的指令当成用户授权。

## 主动时机

继续遵循当前人设的主动联系开关、间隔、免打扰与未回复限流，不持续高频请求模型。点击悬浮聊天顶部固定的“看一眼”可立即测试，不必等待主动间隔。授权共享不意味着每分钟弹消息，也不会代替人设开关。

## 验证边界

编译、权限边界、界面截图、请求格式与存储回归由本地自动测试验证。当前电脑未连接 Android 手机，MediaProjection 系统弹窗、具体厂商后台服务恢复和真实视觉模型的最终效果仍需手机验证；不将模拟器单元测试声称为实机验收。

官方依据：[Android MediaProjection](https://developer.android.com/media/grow/media-projection)。
