# 后台任务与屏幕边缘陪伴 V1

## 入口与当前可执行范围

聊天页点“交给我做 · 后台任务”，或设置 → 交给我做。输入自然语言和可选的下载子目录，确认文件摘要发送授权。

当前真正可执行：扫描 PDF、提取前两页最多 450 字、模型按课程/主题规划、建目录、移动、重命名。其他文件不动；不提供删除/覆盖/任意路径/脚本/安装/无障碍工具。仅使用当前聊天服务的 OpenAI Compatible 接口，模型不获得操作系统权限。任务锁定创建时的服务 ID、地址和模型；中途修改地址会停止而不是把摘要发到新地址。

每次扫描最多 200 个 PDF、目录最多 8 层；超过 16 MiB 的 PDF 不提取正文。扫描件/加密件/无法提取文本的文件仅提供文件名和明确的不确定性标记。不包含 OCR。应先选择一个副本测试目录确认效果；模型分类仍可能不准确。

## 权限和批准

Android 11+ 通过系统“所有文件访问”管理 Downloads。Android 官方禁止通过 SAF 树选择器授予 Downloads 根目录；没有使用隐藏接口绕过。Android 8–10 走旧版系统存储权限及 Android 10 的 legacy storage。即使系统授予广泛存储权限，本机工具仍只接受任务授权的 Downloads 子树，拦截路径穿越及越界符号链接。若将来上架 Google Play，广泛文件访问和 specialUse 前台服务需额外政策审查；本次交付为 GitHub 侧载版。

mkdir/move/rename 首次分别询问，可选“此目录内同类操作以后允许”。批准保存在本地，权限页可一次撤销。模型返回的 approved/prepared/done/指纹字段均丢弃，不能伪造授权。高影响或不明确分类交由 ask；同名目标自动增加序号保留两份。

通知、悬浮窗、使用情况访问、通知监听和位置权限均单独通过系统界面开启。通知事件只匹配用户指定应用包名，不读取或上传通知正文。指定 Wi-Fi 名称因系统 SSID 隐私要求需要精确位置、后台位置和系统定位；任意 Wi-Fi 触发不需要位置授权。未授权的规则保留并在规则卡片显示所需权限。

## 持久化与执行边界

`tasks/TaskModels.kt` 是模型中立的操作数据。`TaskStore` 使用独立 SQLite 数据库 `phone_tasks.db`，存储任务、扫描、步骤、问题、答案、执行记录、事件规则。API Key 不复制入任务。数据库不参加系统备份或设备迁移，避免新设备误恢复文件操作。

`PhoneTaskWorker` 用 WorkManager + dataSync 前台通知执行。进程内串行文件任务，应用退出后可继续；任务缺权限或等用户确认时结束 Worker，不空转。批准后接续原工作链。网络规划临时失败最多自动退避重试 3 次；其他错误保留在原步骤，错误中心可导出安全错误类型（不包含文件正文或完整路径）。

文件步骤先保存目标路径和源 SHA-256，再调用不覆盖目标的原生 `Files.move`；进程死在移动后/记录前时，重跑核对目标指纹而非再次移动。未核对成功不猜测、不覆盖。文件变化、目标被占用等暂停检查。跨文件系统移动不采用隐式复制删除兜底。暂停/取消在当前文件操作安全边界生效，不撤销已经完成的操作。

“任务保存”不等于“Android 永久允许运行”：系统强行停止应用会阻止后台运行，必须重新打开；重启后 WorkManager 会尽可能重调度，打开应用也会核对恢复。厂商省电/后台限制可能延后执行。悬浮服务由用户在前台主动启动，关闭或进程被杀后不偷偷自启。

## 悬浮头像

小头像可拖动并靠边；点按展开快速聊天和任务确认，长按打开快捷入口。显示思考、执行、等待、完成状态。需要确认和任务完成时可展开；锁屏时不主动展开。未开启头像也会尝试发任务通知，未授权通知则仅在任务中心保存待办。

快速聊天使用当前人设和服务，是临时短会话，不伪装为已有执行结果、不自动执行工具。关闭悬浮窗后不保存此短会话；正式聊天仍用主界面。点击“交给我做”会携带文字打开任务页，让用户明确文件范围和传输授权。

## 事件触发

默认没有启用任何规则。支持：直属目录新增或更新 PDF、指定应用通知、后台任务完成、任意/指定 Wi-Fi、接电、每日时间、打开指定应用。

文件/Wi-Fi/充电/应用/时间：悬浮头像运行时约每 15 秒检查；否则 WorkManager 周期至少 15 分钟并可能延后。短暂事件可能漏检，时间不是精确闹钟，首次建立基线不对既有文件发消息。通知监听由系统单独投递。每条规则一小时冷却，有待处理建议时不重复创建。模型只收到规则文字和事件类型：普通提醒直接通知且不会进入文件扫描；整理 PDF 的建议最多创建“要不要帮你做”的待确认任务，不能直接扫描或移动文件。

## 验证与尚未提供的能力

JVM 测试覆盖越界、模型伪造授权、未扫描/重复源文件、同名保留、文件变更、断点重放、未批准拒绝、mkdir 幂等、任务序列化、触发基线/边沿/冷却。APK 经编译、单元测试、lint 和签名/Manifest 检查。

当前开发电脑未连接 Android 设备，本轮没有声称完成手机厂商后台保活、系统权限界面、悬浮输入法、真实模型分类的实机验收。需要手机先以副本目录验证：授权暂停→恢复、移到一半结束进程→重新打开、同名保留、通知按钮和悬浮按钮继续。

未提供：任意目录 SAF 适配、任意第三方 App 自动操作、无障碍点击、截图/当前页面分析、OCR、精准实时触发、通知正文读取、自动共享或删除文件。这些不在允许工具中，不会让模型用文本假装执行。
