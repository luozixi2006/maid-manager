# 3.0.16 — 主动提问与手表身体读数修正

包含 [3.0.15 准备阶段记录](UPDATE_3_0_15.md) 中的全部感知修正：运行中补授权恢复采样、心率预热窗口、采样与同步解耦、身体数据接收与模型上下文诊断。手机和手表需要同时覆盖更新。

## 主动提问修正

- 自动判断的近期互动保护从 30 分钟改为 3 分钟，并直接等到保护结束，不重新随机推迟数小时；正在生成中的聊天仍不会插入主动消息。
- 未回复不再统一锁住 24 小时：“随人设”为 1 小时，明确设置固定/随机间隔时跟随所设最短间隔。全局频率与安静时段仍生效。
- 暂时失败按 2/5/15/30 分钟重试，不因一次错误推迟数小时。缺失/无效 JSON 决策按错误处理，不冒充模型选择安静。
- 设备事件遇到临时防打扰时持久化延期，不直接标记完成；过期事件和撤销同意仍不会强行推送。设备事件也遵守全局联系间隔。
- 人设“测试主动消息”使用真正的 WorkManager 任务、同一模型判断/保存/通知路径。用户明确点击的测试可立即尝试，不受应用内部时间间隔限制，但仍需保存并开启人设联系、不会绕过系统通知权限，不打断正在生成中的回复。
- 诊断实时更新判断阶段、失败原因、下次检查时间；提供系统通知设置入口。不保证 Android 强行停止应用后仍能运行。

3.0.15 流水线未发布：人设名称旧测试使用动态创建时间且默认 JSON 会省略默认值，在跨毫秒解码时会偶发不相等。本版仅固定该测试的时间夹具，保留原有完整比较断言，不修改人设业务。

实机采样、耗电和 DeepSeek 对实际身体记录的回答仍待用户设备安装后验证，不以模拟测试替代实机验收。
